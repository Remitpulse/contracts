# Original contributions

RemitPulse-original work includes the passkey custom account, WebAuthn
integration, bounded sessions, subsidy vault, deployment tooling, and related
tests and documentation.

The router names its Creit-Tech source and revision in its module header. The
airdrop names its OpenZeppelin source and revision. NFT and token support depend
on OpenZeppelin Stellar Contracts v0.3.0. Preserve these attributions and comply
with upstream dependency licenses alongside this repository's MIT license.
